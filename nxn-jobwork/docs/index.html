nxn-jobwork v1.0.0

Az nxn-jobwork a Nexon RP szerver műszakkezelő és fizetéskiosztó rendszere. Ez a script felelős a munkafelvtelrt, a műszak kezdsrt/befejezst, a fizets kiosztásárt, és a munkahelyi NPC-kkel való interakcióért. Az nxn-job adja a munkakör API-t, ez a script mondja meg, hogyan dolgozik a játékos.

⚠️ Hatásköri elválasztás: Az nxn-jobwork NEM tárolja a munkaköröket – ezt az nxn-job teszi. A munkanelküli segély le-/aktiválását az nxn-unemployment automatikusan kezeli a nxn-job:server:jobUpdated event alapján.

Adatbázis séma

CREATE TABLE IF NOT EXISTS `nxn_jobwork_shifts` (
    `id`           INT UNSIGNED  NOT NULL AUTO_INCREMENT,
    `identifier`   VARCHAR(100)  NOT NULL,
    `job`          VARCHAR(50)   NOT NULL,
    `grade`        TINYINT       NOT NULL DEFAULT 0,
    `salary`       INT UNSIGNED  NOT NULL DEFAULT 0,
    `clock_in`     DATETIME      NOT NULL,
    `clock_out`    DATETIME      DEFAULT NULL,
    `duration_sec` INT UNSIGNED  DEFAULT NULL,
    `payout`       INT UNSIGNED  DEFAULT NULL,
    `created_at`   TIMESTAMP     DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (`id`),
    INDEX `idx_shifts_ident` (`identifier`),
    INDEX `idx_shifts_job`   (`job`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

Működési folyamat

Műszak kezds: Játékos NPC → 'Műszak kezdete' → clockIn event → DB INSERT → cache → clockedIn broadcast
Műszak vge: Játékos NPC → 'Műszak vge' → clockOut → salary kérdés → addMoney → fatigue → DB UPDATE → clockedOut broadcast
Timer (60s): Részfizetés (ha 'interval'/'both'), fáradtság tick, max műszak ellenőrzés
Crash-safety: playerLoaded-kor nyitott műszak keresés DB-ben → cache visszatöltés
Auto cleanup: playerUnloading/playerDropped → auto clockOut

-- ACE jog szükséges: nxn.jobwork.admin
-- nxn-dispatch: műszak események figyelese
AddEventHandler('nxn-jobwork:server:clockedIn', function(src, job, grade, clockInTime)
    if job == 'police' or job == 'ems' then
        if GetResourceState('nxn-dispatch') == 'started' then
            exports['nxn-dispatch']:registerActiveUnit(src, { job=job, grade=grade })
        end
    end
end)

AddEventHandler('nxn-jobwork:server:clockedOut', function(src, job, grade, duration, payout)
    if job == 'police' or job == 'ems' then
        if GetResourceState('nxn-dispatch') == 'started' then
            exports['nxn-dispatch']:unregisterUnit(src)
        end
    end
end)

Crashbiztonság

Ha a szerver újságindul míg egy játékos műszakban volt, a playerLoaded event lefutásakor az nxn_jobwork_shifts táblában nyitott (clock_out IS NULL) sort keres a rendszer. Ha talál egyet, visszatölti az activeShifts cache-be és értesíti a játékost. Kilépéskor (playerUnloading / playerDropped) auto clockOut fut le, hogy ne maradjanak nyitott műszakok az adatbázisban.
