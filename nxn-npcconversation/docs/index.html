nxn-npcconversation v1.0.0

Az nxn-npcconversation az NPC-kkel folytatott beszélgetések alap-rendszere. Az NPC-ket a config fájlban vagy más resource-ok exportjaival lehet regisztrálni, minden NPC külön diálógus opciókkal rendelkezik amelyek kliensoldali esemenyeket tudnak kiváltani.

Függőség: nincs kötelező függőség, önállóan fut. Más resource-ok az export API-n keresztül tudnak NPC-ket és diálógusokat hozzáadni.

Diálógus opció formátum

{
    id       = 'vehicle_claim',        -- egyedi azonosító
    label    = 'Jármű kiváltása',       -- UI-ban megjeleno szöveg
    icon     = 'hgi-car-01',           -- HugeIcons neve (hgi- prefix)
    response = 'Kiváltanám a járműt!', -- NPC válasz szövege
    event    = 'nxn-impound:claim',    -- kliensoldali event (nil = csak szöveg)
}

Példák

NPC regisztrálás
Diálógus hozzáadás
Event kezelés
Jármű lefoglalás példa
-- nxn-impound/client.lua:
exports['nxn-npcconversation']:registerNPC('impound_npc', {
    label    = 'Lefoglalási Ügyinzétő',
    model    = 's_m_m_security_01',
    coords   = vector4(404.9, -1631.9, 29.3, 90.0),
    scenario = 'WORLD_HUMAN_STAND_IMPATIENT',
    blip     = { enabled=true, sprite=446, color=1, label='Lefoglalt járművek', scale=0.8 },
    dialogues = {
        {
            id='greet', label='Jó napot!', icon='hgi-message-01',
            response='Jó napot kívánok! Miben segíthetek?', event=nil
        },
    }
})
-- Dinamikus diálógus hozzáadása (például lefoglalt jármű esetén):
exports['nxn-npcconversation']:addDialogue('impound_npc', {
    id       = 'vehicle_claim_ABC123',
    label    = 'Jármű kiváltása (ABC-123)',
    icon     = 'hgi-car-01',
    response = 'Rendben, előkészítem a járművet!',
    event    = 'nxn-impound:client:claimVehicle',
})

-- Eltávolítás kiváltás után:
exports['nxn-npcconversation']:removeDialogue('impound_npc', 'vehicle_claim_ABC123')
-- nxn-impound/client.lua – event fogadása:
AddEventHandler('nxn-impound:client:claimVehicle', function(data)
    -- data.npcId, data.optionId automatikusan át van adva
    TriggerServerEvent('nxn-impound:server:claim', data.optionId)
end)
-- Teljes folyamat: jármű lefoglalás + NPC dialógus integráció

-- 1. Az NPC már regisztrálva van (registerNPC)
-- 2. Jármű lefoglalásakor:
RegisterNetEvent('nxn-impound:client:vehicleImpounded')
AddEventHandler('nxn-impound:client:vehicleImpounded', function(plate)
    exports['nxn-npcconversation']:addDialogue('impound_npc', {
        id       = 'claim_' .. plate,
        label    = 'Jármű kiváltása (' .. plate .. ')',
        icon     = 'hgi-car-01',
        response = 'Megtaláltam! 5000 $ az ára.',
        event    = 'nxn-impound:client:claimVehicle',
    })
end)

-- 3. Kiváltás után eltávolítjuk:
RegisterNetEvent('nxn-impound:client:vehicleClaimed')
AddEventHandler('nxn-impound:client:vehicleClaimed', function(plate)
    exports['nxn-npcconversation']:removeDialogue('impound_npc', 'claim_' .. plate)
end)

Debug

Config.Debug = true esetén minden NPC spawn, diálógus kiválasztás és event kiváltás megjelenik [nxn-npcconversation] [DEBUG] prefixszel.
