nxn-finance

Nexon RP – Központi pénzrendszer

Az nxn-finance a szerver egyetlen, hiteles pénzügyi motorja. Két pénztípust kezel (cash és bank), adatbázisban tárolja az egyenlegeket, minden tranzakciót naplóz, és exportokon keresztül teszi elérhetővé a többi script számára.

Semmilyen más script nem tárolja vagy módosítja közvetlenül a játékos egyenlegét – minden pénzmozgásnak az nxn-finance exportjain kell átmennie.

Fájlstruktúra

nxn-finance/
├── fxmanifest.lua
├── config.lua        – pénztípusok, ATM pozíciók, bank NPC-k
├── shared.lua        – NXN.Finance logger
├── server.lua        – pénzmozgás logika, DB, exportok
├── client.lua        – ATM/NPC regisztrálás, HUD event, exportok
├── html/             – ATM / Bank UI
└── docs/index.html   – ez a fájl

Konfiguráció

A config.lua-ban módosítható minden fontos beállítás.

-- Pénztípusok (cash / bank)
Config.MoneyTypes = {
    ['cash'] = { label = 'Készpénz',   icon = 'hgi-money-02', default = 500  },
    ['bank'] = { label = 'Bankszámla', icon = 'hgi-bank',     default = 2500 },
}
Config.DefaultType = 'cash'   -- ha nincs típus megadva

-- Mentési ciklus (ms)
Config.SaveInterval = 300000  -- 5 perc

-- ATM helyszínek
Config.ATMs = {
    { id = 'atm_grove', label = 'Fleeca ATM – Grove', coords = vector3(...), model = 'prop_atm_01' },
    ...
}

-- Bank NPC-k
Config.BankNPCs = {
    ['fleeca_main'] = {
        label = 'Fleeca Bank', model = 's_f_y_bank_01',
        coords = vector4(...), scenario = 'WORLD_HUMAN_STAND_IMPATIENT',
        blip = { enabled = true, sprite = 108, color = 2, scale = 0.8 }
    },
}

Integrációs példák

nxn-shop – vásárlás

local balance = exports['nxn-finance']:getMoney(src, 'cash')
if balance < item.price then
    exports['nxn-notify']:notifyPlayer(src, 'Nincs elég pénzed!', 'danger')
    return
end
exports['nxn-finance']:removeMoney(src, item.price, 'cash', 'Bolt: ' .. item.label, 'nxn-shop')

nxn-cityhall – bírság befizetés

-- RÉGI (javítandó):
exports['nxn-bank']:removeBalance(src, fine.amount)

-- ÚJ:
local ok = exports['nxn-finance']:removeMoney(src, fine.amount, 'bank', fine.reason, 'nxn-cityhall')
if not ok then
    Notify(src, 'Nincs elég pénz a bankban!', 'danger')
    return
end

nxn-jobs – fizetés kifizetése

exports['nxn-finance']:addMoney(src, salary, 'bank', 'Heti fizetés', 'nxn-jobs')

Tranzakció log (admin)

local log = exports['nxn-finance']:getTransactionLog(src, 20)
for _, entry in ipairs(log) do
    print(entry.action, entry.amount, entry.reason, entry.created_at)
end
