nxn-keys v1.0.0

Az nxn-keys a Nexon RP szerver járműkulcs- és zárolásrendszere. Kezeli a játékosok kulcsait, a jármű zárolás/nyitás logikát, kulcsátadást más játékosoknak, és az nxn-engine motorindítás-hitelesítését az auth callback mechanizmuson keresztül.

    `is_owner`    TINYINT(1)   DEFAULT 0,

Auth callback folyamat

1
nxn-engine registerStartAuthCallback – nxn-keys regisztrálja az engine auth callbackjét
2
Játékos motort akar indítani – az nxn-engine meghívja a callbacket
3
hasKeyForPlate(plate) – szinkron cache-ellenőrzés, true/false return
4
false → nxn-engine megtagadja az indítást, notify jelenik meg
5
nxn-hotwire bypass – a hotwireStart() kikerüli ezt az ellenőrzést

Export használati példák

Kliens (Lua)
Szerver (Lua)
nxn-garage / nxn-vehicleshop
-- Kulcskarika megnyitása
exports['nxn-keys']:openKeyring()

-- Van-e kulcsa az aktuális járműhöz? (szinkron)
local plate = GetVehicleNumberPlateText(GetVehiclePedIsIn(PlayerPedId(), false))
if exports['nxn-keys']:hasKeyForPlate(plate) then
    print('Van kulcsom!')
end
-- Kulcs adása (pl. spawn után)
exports['nxn-keys']:giveKey(src, plate, true)  -- true = tulajdonosi kulcs

-- Van-e kulcsa?
if exports['nxn-keys']:hasKey(src, plate) then
    print('Van kulcsa')
end

-- Összes kulcs megvonása (eladásnál)
exports['nxn-keys']:revokeAllKeys(plate)

-- Kulcstulajdonosok lekérése
local holders = exports['nxn-keys']:getKeyHolders(plate)
for _, h in ipairs(holders) do
    print(h.identifier, h.is_owner)
end
-- nxn-garage server.lua-ban (spawn után):
if GetResourceState('nxn-keys') == 'started' then
    exports['nxn-keys']:giveKey(src, plate, false)  -- nem tulajdonosi kulcs
end

-- nxn-vehicleshop server.lua-ban (vásárlás után):
if GetResourceState('nxn-keys') == 'started' then
    exports['nxn-keys']:giveKey(src, plate, true)   -- tulajdonosi kulcs
end
