/* JS – értesítés hozzáadása */
function showNotify(msg, type = '') {
    const el = document.createElement('div');
    el.className = `nxn-notify ${type}`;
    el.innerHTML = `<i class="hgi hgi-stroke hgi-information-circle"></i><span>${msg}</span>`;
    document.getElementById('notify-container').appendChild(el);
    setTimeout(() => el.remove(), Config.NotifyDuration);
}

Dizájn szabályok

Guidelines

Csak design tokenek

Soha ne írj hard-coded hex vagy rgb értéket – mindig var(--nxn-*) tokent használj.

Csak HugeIcons

Más ikonkönyvtár (FontAwesome, Material stb.) nem megengedett. Mindig hgi-stroke stílus.

Moduláris UI

Minden komponens önállóan újrafelhasználható – panel, notify, badge, input saját CSS osztállyal rendelkezik.

Réteg sorrend

HUD: z-index 100–999, értesítés: 9999, modal/panel: 10000+. Soha ne keverj z-index szinteket.

Animáció

Megjelenés: nxnFadeIn .2s ease. Hover: opacity/color .15s. Nincs backdrop-filter.

Export kompatibilitás

Minden resource exportálja UI-függvényeit. Más nxn-* resource-ok ezeket szabadon hívhatják.

Do / Don't

Helyes
  • Használj var(--nxn-accent) tokent
  • Minden panel rendelkezzen fejléccel
  • HugeIcons stroke stílussal
  • nxnFadeIn animáció megjelenésnél
  • 4px rács alapú margók és paddingek
  • Exportok minden resource-hoz
Helytelen
  • Hard-coded színértékek (#5b6af0 közvetlenül)
  • backdrop-filter használata
  • Más ikonkönyvtár (FA, MDI stb.)
  • Framework (ESX, QBCore) integráció alapból
  • Véletlenszerű z-index értékek
  • Egységesítő CSS token nélküli saját stílus

Animációk

Motion

Az összes Nexon animáció rövid (max. 300ms) és minimális. A nxnFadeIn az egyetlen globálisan kötelező keyframe.

AnimációIdőtartamHasználat
nxnFadeIn.2s easePanel, értesítés, modal megjelenése
opacity transition.15sGomb hover, ikon hover
color transition.15sNav link hover, btn-icon hover
width transition.3sHUD progress bar értékváltozás
border-color transition.15sInput focus
@keyframes nxnFadeIn {
    from { opacity: 0; transform: translateY(-8px); }
    to   { opacity: 1; transform: translateY(0);    }
}

/* Megjelenő elemeken */
.nxn-panel, .nxn-notify {
    animation: nxnFadeIn .2s ease;
}
