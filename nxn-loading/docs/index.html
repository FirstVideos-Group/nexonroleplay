Overview

Az nxn-loading felelős a szerver betöltési képernyőjének megjelenítéséért, a játékosok várólistájának kezeléséért, a modulok vizuális betöltési folyamatáért és a háttérzene lejátszásáért.

A script a Nexon Design System egységes dizájnnyelvét használja. Teljesen konfigurálható a config.lua-ból – szerver neve, leírás, szabályok, billentyűparancsok, zenefájl, modulok.

Kliens Szerver Exportok loadscreen_manual_shutdown Lua 5.4

Szabályok (Config.Rules)

Tömb, minden elem: { icon = 'hgi-xxx', title = '…', text = '…' }. Az icon a HugeIcons osztálynév (hgi- prefix nélkül is elfogadott).

Billentyűparancsok (Config.Keybinds)

Tömb, minden elem: { key = 'F1', desc = 'Leírás' }.

Net Events

Events
Event neveIrányLeírás
nxn-loading:server:playerReadyKliens → SzerverKliens jelzi, hogy betöltési képernyőn van, kéri a szerver adatokat
nxn-loading:server:enterGameKliens → SzerverJátékos megnyomta az Enter gombot, kéri a belépést
nxn-loading:client:serverDataSzerver → KliensSzerver elküldi a szerver adatokat (név, szabályok, billentyűk stb.)
nxn-loading:client:queueUpdateSzerver → KliensVárólista pozíció frissítés
nxn-loading:client:doEnterSzerver → KliensSzerver engedélyezi a belépést, kliens shutdown-olja a loadscreent

Kód példák

Examples

Export használat más resource-ból

Kliens
Szerver
Modul progress
-- Más resource kliens oldaláról

-- Betöltés kész-e?
local done = exports['nxn-loading']:isLoadingDone()
if done then
    -- a játékos már bent van
end

-- Állapot szöveg beállítása
exports['nxn-loading']:setStatusText('Karakteradatok betöltése…')

-- Kényszer belépés (pl. admin)
exports['nxn-loading']:forceEnter()
-- Más resource szerver oldaláról

-- Várakozók száma
local qLen = exports['nxn-loading']:getQueueLength()
print('Várakozók: ' .. qLen)

-- Játékos belépett-e már?
local src = source
if exports['nxn-loading']:isPlayerConnected(src) then
    -- logika
end

-- Kényszerített belépés
exports['nxn-loading']:forceEnter(src)
-- Külső resource saját betöltési folyamatát jelzi
-- a loading screen modul listájában megjelenik

-- Kliens oldalon, pl. nxn-inventory resource-ból:
exports['nxn-loading']:updateModuleProgress(
    'Inventory adatok',  -- modul neve
    50                      -- százalék (0-100)
)

-- Amikor kész:
exports['nxn-loading']:updateModuleProgress('Inventory adatok', 100)

Folyamatábra

Flow

A loading screen életciklusa a csatlakozástól a belépésig:

Játékos csatlakozik
    │
    ▼
[Szerver] playerConnecting event
    │
    ├── Ha server tele → Várólista (pozíció frissítés 5s-ként)
    │
    └── Ha van hely → deferrals.done()
           │
           ▼
[Kliens] onClientResourceStart → playerReady event küldése
           │
           ▼
[Szerver] serverData event → visszaküldi szerver infót
           │
           ▼
[HTML/JS] Modul animáció lejátszása (szimulált betöltés)
    + Zene lejátszás
    + Szabályok / Billentyűk / Infó tab
           │
           ▼
[100% elért] → 'Irány a város!' gomb megjelenik
           │
    Játékos megnyomja a gombot
           │
           ▼
[JS] Zene fade out → Screen fade out → enterGame NUI callback
           │
           ▼
[Kliens] enterGame server event
           │
           ▼
[Szerver] doEnter client event
           │
           ▼
[Kliens] ShutdownLoadingScreen() → Játékos bent van!
