nxn-shop v1.0.0

Az nxn-shop az általános, újrafelhasználható boltrendszer. NPC kereskedőket regisztrál az nxn-npcconversation-ön keresztül, vásárlást és eladást kezel nxn-inventory + nxn-finance exportokon át, opcionális véges készlet (stock) rendszerrel és sell tabbal.

Fájlstruktúra

nxn-shop/
├── fxmanifest.lua      ← dep: nxn-inventory, nxn-notify, nxn-npcconversation, nxn-finance, nxn-database
├── config.lua          ← Config.Shops, Config.StockRefillInterval, Config.SellEnabled
├── shared.lua          ← NXN.Shop logger
├── client.lua          ← NPC regisztrálás, UI megnyitás, NUI callbackek, exportok
├── server.lua          ← vásárlás/eladás logika, stock DB, registerShop, exportok
├── html/               ← Nexon design: buy + sell tab, qty selector, kosár
└── docs/index.html

Függőségek

nxn-inventory nxn-notify nxn-npcconversation nxn-finance nxn-database

Export használati példák

e1 – Runtime bolt regisztrálás
e2 – Stock kezelés (admin)
e3 – nxn-food integráció
e4 – Bolt megnyitás kliensről
-- nxn-jobs server.lua – munkahelyi bolt regisztrálása
exports['nxn-shop']:registerShop('mechanic_shop', {
    label    = 'Szerelő Kellékek',
    category = 'general',
    canSell  = false,
    items    = {
        { item = 'repair_kit', price = 1200, stock = nil },
    },
})

-- Resource leállításkor:
exports['nxn-shop']:unregisterShop('mechanic_shop')
-- Admin script – stock visszatöltés eseményre:
RegisterCommand('restockshop', function(src, args)
    local shopId   = args[1]
    local itemName = args[2]
    local amount   = tonumber(args[3]) or 50
    exports['nxn-shop']:setShopStock(shopId, itemName, amount)
end, true)

-- Aktuális stock lekérdezése:
local stock = exports['nxn-shop']:getShopStock('pawn_shop_1', 'phone')
print('Telefon készlet: ' .. tostring(stock))
-- nxn-food csak a fogyasztást kezeli (animáció + nxn-needs).
-- A bolt vásárlás az nxn-shop Config.Shops-ban van (burger_shot_1, upnatom_1 stb.)
-- nxn-food server.lua – ha nxn-shop fut, delegáljuk a vásárlást:
if GetResourceState('nxn-shop') == 'started' then
    -- A vásárlás nxn-shop-on keresztül megy,
    -- nxn-food csak az nxn-food:server:use eventet kezeli
    NXN.Food.Info('nxn-shop fut, bolt vásárlás delegálva.')
end
-- Kliens oldali megnyitás más resource-ból:
exports['nxn-shop']:openShop('247_supermarket_1', 'buy')

-- Ellenőrzés:
if exports['nxn-shop']:isShopOpen() then
    print('Bolt nyitva van')
end

-- Bezárás:
exports['nxn-shop']:closeShop()
