nxn-autoseatbelt v1.0.0

Az nxn-autoseatbelt az nxn-seatbelt kiegészítője: járműtípus- és modell-lista alapján automatikusan beköti a biztonsági övet a járműbe szállás után.

Függőség: Az nxn-seatbelt resource-nak futnia kell. A script dependencies listaból automatikusan el is indítja.

Döntési prioritás

Amikor a játékos járműbe száll, az alábbi sorrendben dönt a rendszer:

1 ExcludedModels / runtimeExcludedModels Soha nem kötödik be → STOP
2 ExcludedClasses Kizart osztály → STOP
3 AutoModels / runtimeAutoModels Explicit feherlista → IGEN
4 AutoClasses / runtimeAutoClasses Osztály match → IGEN
5 Egyéb Nem kötődik be automatikusan

Példák

Tesztvezetés
Modell runtime hozzaadás
Event figyalés
-- nxn-testdrive/client.lua
-- Tesztvezetesnel MINDIG kotodik az ov, fuggettlenul a jarmu tipusatol:

AddEventHandler('nxn-testdrive:started', function(vehicleModel)
    -- Kenyszer-bekotes (kihagyja a lista ellenorzest)
    exports['nxn-autoseatbelt']:forceAutoFasten()
end)

AddEventHandler('nxn-testdrive:ended', function()
    -- Ha a tesztvezetes vege utan sem kell auto, letiltjuk
    exports['nxn-autoseatbelt']:setEnabled(false)
    exports['nxn-seatbelt']:unfasten()
    -- Tesztvezetes utan visszakapcsoljuk
    Wait(500)
    exports['nxn-autoseatbelt']:setEnabled(true)
end)
-- Runtime modell hozzaadas (pl. egy esemeny auto-ja):
exports['nxn-autoseatbelt']:addAutoModel('entityxf')  -- F1 auto
exports['nxn-autoseatbelt']:addAutoModel('buzzard2')  -- helikopter (osztalyban kizart, de itt explicit)

-- Ideiglenes kizaras (pl. mentoszolgalatnal nem kotodik):
exports['nxn-autoseatbelt']:excludeModel('ambulance')

-- Visszavonas:
exports['nxn-autoseatbelt']:unexcludeModel('ambulance')
-- Auto-bekotes esemeny figyelese (pl. loggolas, statisztika):
AddEventHandler('nxn-autoseatbelt:fastened', function(data)
    print(('Auto-bekotes: model=%s entId=%d'):format(
        data.model, data.vehicle
    ))
    -- Pl. szerver-loggolas:
    TriggerServerEvent('nxn-logs:server:seatbelt', {
        model    = data.model,
        autoFast = true,
    })
end)
