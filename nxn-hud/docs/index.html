nxn-hud v1.0.0

Az nxn-hud a Nexon szerver moduláris játékos HUD-ja. Minden elem külön modul fájlban él, egyszerűen bővíthető. Az nxn-needs exportjait és eventjeit használja, az nxn-notify rendszerrel kompatibilis.

Függőség: nxn-needs – a HUD hunger/thirst/stress adatai innen jönnek.

Példák

HUD el/megmutatása

Pénz / Munka adat
Stress notify
Bovítés: új modul
-- HUD eltuntetese (pl. cutscene alatt)
exports['nxn-hud']:setVisible(false)

-- HUD visszahozasa
exports['nxn-hud']:setVisible(true)
-- Penz modul bekapcsolasa
exports['nxn-hud']:setModule('money', true)

-- Stress modul kikapcsolasa
exports['nxn-hud']:setModule('stress', false)

-- Osszes modul allapot lekerese
local states = exports['nxn-hud']:getAllModuleStates()
for name, enabled in pairs(states) do
    print(name, enabled)
end
-- nxn-finance / nxn-job resource kliens oldalon:
exports['nxn-hud']:updateModuleData('money', {
    amount   = 15000,
    currency = '$'
})

exports['nxn-hud']:updateModuleData('job', {
    name  = 'Rendőr',
    grade = 'Főhadnagy'
})
-- Ha a stress magas, notify is erkezik (nxn-needs + nxn-notify kombinalva)
-- nxn-needs event alapon a stress.lua kezeli a show/hide-ot
-- Notify kuldése peldaul:
AddEventHandler('nxn-needs:client:updated', function(needs)
    if needs.stress > 80 then
        exports['nxn-notify']:warning('Nagyon stresszes vagy!')
    end
end)
-- Uj modul hozzaadasa (pl. nxn-hud/modules/fuel.lua):

-- 1. Config.lua-ban:
Config.Modules.fuel = { enabled = true, alwaysVisible = false,
                        threshold = 20, hideDelay = 3000, order = 11 }

-- 2. modules/fuel.lua:
CreateThread(function()
    while true do
        Wait(1000)
        if not hudVisible or not moduleStates['fuel'] then goto continue end
        -- ... lekérdezés ...
        NXN.HUD.Send('updateModule', { module = 'fuel', value = fuelValue })
        ::continue::
    end
end)

-- 3. html/index.html-ben egy uj .hud-module blokk
-- 4. fxmanifest.lua client_scripts-be: 'modules/fuel.lua'
