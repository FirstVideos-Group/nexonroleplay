nxn-signs v1.0.0

Az nxn-signs zóna-alapú jelzőtábla-megjelenítő rendszer. SVG fájlokat használ, fade-in/out animációkkal, két kategóriában: nagy és infó táblák.

Kategóriák

large Nagy tábla

Képernyő tetején középen jelenik meg, 96px magas SVG. Időkorlátos vagy örök. Pl. területbe lépési tábla.

info Info tábla

Jobb oldal közepén jelenik meg, 64px magas SVG. Folyamatosan látszik amíg a játékos a zónában van. Pl. sebesség, vontatási zóna.

Config zóna mezoők

MezőTípusLeírás
labelstringMegjelenített szöveg a tábla alatt
category'large'|'info'Tábla típusa
filestringSVG fájlnév a signs/ mappában
centervector3Zóna középpontja (GTA koordináta)
radiusnumberZóna sugara méterben
durationnumber|nilMásodperc amig látszik; nil = folyamatos
fadeInnumberFade-in idő ms-ban
fadeOutnumberFade-out idő ms-ban

Példák

Manuális megjelenítés
Runtime zóna
Saját SVG tábla
-- Manualis megjelenitese egy esemenynel (pl. verseny rajtnal):
exports['nxn-signs']:showSign('race_start', {
    file     = 'race_start.svg',
    category = 'large',
    label    = 'Verseny kezdodik!',
    duration = 5,       -- 5 masodpercig latszik
    fadeIn   = 800,
    fadeOut  = 600,
})

-- Elrejtese:
exports['nxn-signs']:hideSign('race_start')
-- Runtime zona regisztralasa (pl. nxn-impound terulete):
exports['nxn-signs']:registerZone('impound_zone', {
    label    = 'Lefoglalt terulet',
    category = 'info',
    file     = 'towing_zone.svg',
    center   = vector3(400.0, -1650.0, 29.0),
    radius   = 80.0,
    duration = nil,    -- folyamatos
    fadeIn   = 400,
    fadeOut  = 300,
})

-- Eltavolitasa ha a zona megszunik:
exports['nxn-signs']:unregisterZone('impound_zone')
-- Sajat SVG tabla letrehozasa:
-- 1. Helyezd el az SVG fajlt: nxn-signs/signs/sajat_tabla.svg
-- 2. Regisztrald a zona-t a config.lua-ban:

Config.Zones['sajat_zona'] = {
    label    = 'Sajat Zona',
    category = 'large',       -- vagy 'info'
    file     = 'sajat_tabla.svg',
    center   = vector3(X, Y, Z),
    radius   = 100.0,
    duration = 4,             -- 4 mp latszik
    fadeIn   = 600,
    fadeOut  = 400,
}

-- Vagy runtime exporttal:
exports['nxn-signs']:registerZone('sajat_zona', { ... })

Debug

Config.Debug = true eseten minden zóna belépés/kilépés, megjelenítés és eltűnés megjelenik [nxn-signs] [DEBUG] prefixszel, beleértve a távolságot és a duration leállást.
