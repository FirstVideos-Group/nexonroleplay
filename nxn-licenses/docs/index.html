Áttekintés

Az nxn-licenses a Nexon RP szerver igazolvány- és engedélykezelő rendszere. Karakterenként tárolja adatbázisban az igazolványokat (két külön tábla: nxn_licenses és nxn_license_requests). Az igénylés kiváltáskor nem azonnal kerül a játékoshoz, hanem konfigurálható idő múltán („feldolgozási idő”). Minden igazolványnak lejárati ideje van, amittől újra igényelhető. A játékos /idcard parancsal nyár meg a UI-t, ahol megtekintheti, igényelheti és felmutathatja igazolványait. Az adatok az nxn-identity exportáiból származnak.

Játékos

A feldolgozó tick minden Config.ProcessInterval másodpercben fut. Az igénylés ready_at mezőjét hasonlítja az aktuális UTC időhöz. Ha a játékos online, azonnal szinkronizál és nxn-notify ertésítést küld. Ha offline volt az igazolvány kiadásakor, a következő bejelentkezéskor töltődik be.

Színrögzítés módjai

Két helyen állítható egy típus színe – CSS előny a config felett:

config.lua (Lua)
style.css (CSS)
-- config.lua-ban a color mezőt állítsd be:
{
    id    = 'weapon_license',
    color = '#e11d48',   -- mély piros – CSS érték vagy hex
    -- ... többi mező
}
/* style.css alján – ez felülírja a JS által állított értéket is */
.lic-type-weapon_license {
    --lic-color: #e11d48;
}

/* Ha új típust adsz hozzá, az osztaly mindig: lic-type-{id} */
.lic-type-taxi_license {
    --lic-color: #f59e0b;
}
A shimmer (ragyogás) effekt sebessége és intenzitása a @keyframes licShimmer és a .id-card::before background értékeiben állítható a style.css-ben.

Példák

Jogosítvány ellenőrzés
Visszavonás (Rendőr)
Közvetlen kiadás (Admin)
Kliens export
-- Jarmű használatkor: van-e érvényes jogosítvány?
-- nxn-vehicle script szerver oldal
AddEventHandler('nxn-vehicle:server:entered', function(src, class)
    if class == 'car' then
        local ok = exports['nxn-licenses']:hasLicense(src, 'drivers_license')
        if not ok then
            exports['nxn-notify']:notifyPlayer(src,
                'Nincs érvényes jogosítványod!', 'warning'
            )
        end
    end
end)
-- Rendőr visszavonja a jogosítványt (nxn-police script)
-- targetSrc: a megallított játékos source-a
exports['nxn-licenses']:revokeLicense(targetSrc, 'drivers_license')
-- Automatikusan notify-t küld a céljátékosnak, DB-ben is revoked=1
-- Admin / cégrendszer közvetlenül ad ki igazolványt (azonnali):
local ok = exports['nxn-licenses']:grantLicense(src, 'police_badge')
if ok then
    exports['nxn-notify']:notifyPlayer(src,
        'Rendőrségi kártya kiallitva.', 'success'
    )
end
-- Kliens oldal: megnyítás más scriptből
exports['nxn-licenses']:openLicenses()

-- Helyi cache (kliens)
local lics = exports['nxn-licenses']:getLocalLicenses()
if lics['drivers_license'] then
    print('Van jogosítvány (kliens cache)')
end
nxn-licenses-t az ensure listában az nxn-database, nxn-identity és nxn-notify után kell elindítani.
Az nxn-licenses:server:loaded szerver eventet figyelheted más scriptekben is, hogy automatikusan ellenőrzéseket végezz a játékos belépésekor.
