nxn-notify v1.0.0

Az nxn-notify a Nexon szerver vizuális értesítési rendszere. Minden más nxn-* resource ezen keresztül jelenít meg értesítéseket – szerver- és kliens-exportok egyaránt elérhetők. A megjelenés a Nexon Design System notification komponensét követi.

Nincsenek külső függőségek – az nxn-notify önállóan fut, bármely más resource meghívhatja.

Előnézet

Értesítés típusok
Értesítés
Ez egy általános értesítés.
Sikeres
A művelet sikeresen végrehajtva.
Hiba
Hiba történt a folyamat során.
Figyelmeztetés
Figyelem: ez a művelet nem visszavonható.

Export használati példák

Szerver → Játékos
Broadcast
Kliens oldal
Egyedi cím + időtartam
-- Bármely nxn-* resource server.lua-jából:
exports['nxn-notify']:success(source, 'Autó sikeresen garázsba helyezve!')
exports['nxn-notify']:danger(source, 'Nincs elég pénzed!')
exports['nxn-notify']:warning(source, 'Figyelj, alacsony az életed!')
exports['nxn-notify']:info(source, 'A szerver újraindul 5 perc múlva.')

-- Általános típus-választós hívás:
exports['nxn-notify']:notify(source, 'Üzenet szöveg', 'success')
-- Minden online játékosnak egyszerre:
exports['nxn-notify']:broadcast('A szerver újraindul 5 perc múlva!', 'warning')
exports['nxn-notify']:broadcast('Esemény kezdődik!', 'info', 6000)
-- Kliens oldali resource-ból (pl. nxn-hud client.lua):
exports['nxn-notify']:success('Sikeresen bejelentkeztél!')
exports['nxn-notify']:danger('Éhes vagy, egyél valamit!')

-- Ellenőrzés után:
local needs = exports['nxn-needs']:getLocalNeeds()
if needs.hunger < 20 then
    exports['nxn-notify']:warning('Nagyon éhes vagy!')
end
-- Egyedi cím és időtartam megadása:
exports['nxn-notify']:notify(source, 'Megkaptad a rendőr munkakört.', 'success', 6000, 'Munkakör')

-- Kliens oldalon:
exports['nxn-notify']:notify('Elkészült a járműved.', 'info', 5000, 'Garázs')

Debug logok

A Config.Debug = true beállítással részletes naplókat kapsz minden értesítés-küldésről, net event fogadásról és NUI üzenetről. Éles szerveren kapcsold ki.
