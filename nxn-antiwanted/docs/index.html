nxn-antiwanted
Játék alapértelmezett körözési rendszerének teljes kikapcsolása
v1.0.0 Stabil Client + Server

Áttekintés

Az nxn-antiwanted script teljes mértékben kikapcsolja a GTA5 alapértelmezett körözési (Wanted) rendszerét. Ez magában foglalja:

  • A körözési szint folyamatos nullázását
  • A dispatch szolgálatok letiltását (rendőrhívás blokk)
  • A rendőrségi járőrök viselkedésének tiltását
  • A maximális körözési szint 0-ra állítását
  • Export-alapon ideiglenes visszaengedélyezés (pl. rendőrségi eseményekhez)
Az export API-n keresztül más resource-ok (pl. rendőrségi script) ideiglenesen visszakapcsolhatják a rendszert.

Konfiguráció

Minden beállítás a config.lua fájlban kezelhető.

Config.Debug boolean Debug logüzenetek megjelenítése a konzolon
Config.ClearOnSpawn boolean Spawn/belépés után azonnal nullázza a körözési szintet
Config.ClearInterval integer Folyamatos nullázás gyakorisága ms-ban (0 = minden tick)
Config.DisableDispatch boolean GTA dispatch szolgálatok letiltása (rendőr hívás blokk)
Config.DispatchServices table Letiltandó dispatch szolgálat ID-k (1-15)
Config.DisableCopSpawn boolean Rendőrségi járőrök térképen/világban való ignorálása
Config.BlockWantedEvents boolean Max wanted szint 0-ra állítása (rendszer szintű blokk)
Config.AllowWanted boolean Alapértelmezetten tiltott; ha true, a script függesztve van

Export API

Példakódok

Rendőrségi script – körözés visszakapcsolása

-- Más resource-ból (pl. nxn-police) kliens oldalon:
local aw = exports['nxn-antiwanted']

-- Körözés bekapcsolása (pl. játékos rendőr-RP eseménybe kerül)
aw:enableWanted()

-- Esemény végén visszakapcsol a védelem
aw:disableWanted()

Aktuális körözési szint lekérése

local level = exports['nxn-antiwanted']:getWantedLevel()
if level > 0 then
    print('Aktív körözés: ' .. level .. ' csillag')
end

Szerver oldalról – körözés nullázása egy játékosnál

-- Szerver oldali scriptből (pl. admin tool):
exports['nxn-antiwanted']:clearWantedForPlayer(source)
exports['nxn-antiwanted']:disableWantedForPlayer(source)

Config.AllowWanted dinamikus kezelése

Ha a Config.AllowWanted = true értékre van állítva induláskor, a script nem töröl semmit – csak az exportok segítségével kerülhet tiltott módba.
