nxn-identity v1.0.0

Az nxn-identity kezeli a játékos karakterének adatait: személyes azonosítók, megjelenés (skin), arcvonások és mentett pozíció. Szorosan együttműködik az nxn-database-zel.

Függőség: nxn-database (identifier + registerTable + playerLoaded event). Az nxn-notify opcionális.

Példák

Igazolvány integráció
Életkor ellenőrzés
Skin újraalkalmazás
-- nxn-idcard/server.lua – igazolvány adatlap
RegisterNetEvent('nxn-idcard:server:getMyData')
AddEventHandler('nxn-idcard:server:getMyData', function()
    local src  = source
    local ident = exports['nxn-identity']:getIdentity(src)
    if not ident then
        TriggerClientEvent('nxn-notify:client:send', src, 'Nincs karaktered!', 'danger')
        return
    end

    TriggerClientEvent('nxn-idcard:client:showCard', src, {
        name      = exports['nxn-identity']:getFullName(src),
        gender    = ident.gender == 0 and 'Férfi' or 'Nő',
        birthdate = exports['nxn-identity']:getBirthDate(src),
        age       = exports['nxn-identity']:getAge(src),
    })
end)
-- Alkohol/szórakozóhely belépés ellenőrzés:
local age = exports['nxn-identity']:getAge(source)
if not age or age < 18 then
    TriggerClientEvent('nxn-notify:send', source, 'Csak 18+ léphet be!', 'danger')
    return
end
-- nxn-clothing után skin frissités (kliens oldal):
AddEventHandler('nxn-clothing:outfitApplied', function()
    exports['nxn-identity']:reapplySkin()
end)

-- Vagy skin mentés és újratöltés:
TriggerServerEvent('nxn-identity:server:updateSkin', {
    hair_style = 3, hair_color = 1, hair_highlight = 29,
    skin_color = 0, eye_color = 7,
    outfit = { {11, 42, 0}, {8, 15, 0} },
})

Debug

Config.Debug = true esetén minden DB lekérdezés, skin alkalmazás, spawn esemény és pozíciómentés megjelenik [nxn-identity] [DEBUG] prefixszel a konzolban.
