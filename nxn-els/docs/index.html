nxn-els v1.2.0

Emergency Lighting System – Nexon FiveM

Az nxn-els a Nexon szerverszinkronizált vészjelző rendszere. Fényfokozatok (stage), villogási pattern motor, környezeti fényreflexió, misc fények (0–25), sziréna hang, irányjelzők, jogosultságkezelés (job + admin ace) és teljes export API – teljesen standalone, framework-függés nélkül.

ELS jogosultság kétféleképpen adható: job alapján (nxn-police / nxn-ems hívja az exportot) vagy admin ace jogosultsággal (nxn.els.admin) – utóbbi esetén job és jármű-whitelist sem szükséges.

Fényfokozatok (Stage)

0
Kikapcsolt

Nincs fény, nincs hang. Alapállapot.

1
CODE 1

Csendes szolgálat – steady pattern, sziréna hang nélkül.

2
CODE 2

Fény + sziréna – alternating pattern.

3
CODE 3

Teljes riasztás – wigwag pattern, magas prioritású hang.

Villogási Pattern Rendszer

Minden stage egy pattern-t futtat, amely lépéssorozatként van definiálva a Config.Patterns-ben. Minden lépés megadja, melyik extra (0–14) és misc fény (0–25) legyen be/ki, és mennyi ideig tartson.

steady

Nem villog, folyamatosan be van kapcsolva. CODE 1-hez.

alternating

Bal/jobb felváltva 120ms-onként. CODE 2 alapértelmezett.

wigwag

Gyors alternating 80ms-onként. CODE 3 alapértelmezett.

pileon

Minden egyszerre villog. Mentő (ambulance) CODE 2/3-hoz.

Saját pattern hozzáadása config.lua-ban:

Config.Patterns['sajat'] = {
    { extras = {[1]=true, [2]=false, [3]=true }, miscs = {[0]=true},  dur = 100 },
    { extras = {[1]=false,[2]=true,  [3]=false}, miscs = {[0]=false}, dur = 100 },
}

A pattern automatikusan körkörösen ismétlődik, amíg az adott stage aktív. Stage váltáskor azonnal átáll az új pattern-re.

Környezeti Fényreflexió

A SetVehicleLightMultiplier natív segítségével a villogó fények ritmikusan „visszaverődnek" a padlóra, falakra és közeli járművekre – ugyanúgy, ahogyan a MISS-ELS is működik.

Config.EnvLight = {
    enabled    = true,
    multiplier = 3.5,   -- minél nagyobb, annál erősebb visszaverődés (alap: 1.0)
    tickMs     = 80,    -- frissítési sűrűség ms-ban
}

A rendszer az aktív extra-k állapotát figyeli, és a multiplier-t szinkronban pulzáltatja a pattern lépéseivel. Kikapcsolt ELS-nél automatikusan visszaáll 1.0-ra.

Admin Jogosultság

Az admin jogosultság szerver-oldalon van ellenőrizve (IsPlayerAceAllowed) – a kliens nem tudja hamisítani.

Adminként az ELS job és jármű-whitelist nélkül is használható bármely járművön. Egyetlen sor szükséges a server.cfg-ben:

add_ace group.admin nxn.els.admin allow

Az ace neve módosítható a config.lua-ban:

Config.AdminAce = 'nxn.els.admin'  -- tetszőleges ace név

-- nxn-police client.lua – bejelentkezéskor
AddEventHandler('nxn-police:client:onDuty', function(job)
    exports['nxn-els']:setJobPermission(job, true)
end)

AddEventHandler('nxn-police:client:offDuty', function()
    exports['nxn-els']:setJobPermission('', false)
end)

-- ELS állapot lekérdezése
local stage   = exports['nxn-els']:getStage()        -- 0..3
local label   = exports['nxn-els']:getStageLabel()   -- 'CODE 2'
local active  = exports['nxn-els']:isElsActive()     -- true/false
local pattern = exports['nxn-els']:getCurrentPattern() -- 'wigwag'
-- nxn-police server.lua – jogosultság megadása
RegisterServerEvent('nxn-police:server:onDuty', function(job)
    local src = source
    exports['nxn-els']:setPlayerJobPermission(src, job, true)
end)

RegisterServerEvent('nxn-police:server:offDuty', function()
    local src = source
    exports['nxn-els']:setPlayerJobPermission(src, '', false)
end)

-- Ellenőrzés (job VAGY admin egyaránt true-t ad)
if exports['nxn-els']:playerHasPermission(src) then
    -- játékos ELS-t használhat
end
-- Admin státusz ellenőrzése szerver-oldalon
local isAdm = exports['nxn-els']:isPlayerAdmin(src)
if isAdm then
    print('Ez a játékos admin – ELS whitelist bypass aktív')
end

-- server.cfg beállítás (egyszer kell):
-- add_ace group.admin nxn.els.admin allow

-- Ha más ace nevet szeretnél (config.lua):
-- Config.AdminAce = 'nxn.els.admin'

-- Kliens oldalon is lekérdezhető:
local amIAdmin = exports['nxn-els']:isAdmin()
-- Dispatch / CAD – összes aktív ELS jármű lekérése
local states = exports['nxn-els']:getAllVehicleStates()
for netId, state in pairs(states) do
    if state.stage >= 2 then
        print(('Jármű %d CODE %d-ben jár (owner: %d)'):format(
            netId, state.stage, state.owner))
    end
end

-- Stage kényszerítése (pl. adminpanel, dispatch)
exports['nxn-els']:forceStage(netId, 0)  -- kikapcs
exports['nxn-els']:forceStage(netId, 3)  -- CODE 3
-- Az nxn-els automatikusan frissíti az nxn-vehicle-hud
-- siren modulját, ha Config.IntegrateVehicleHud = true.
-- Manuálisan is hívható:
exports['nxn-vehicle-hud']:setSiren(true,  'CODE 2')
exports['nxn-vehicle-hud']:setSiren(false, nil)

-- A vehicle-hud config.lua-ban engedélyezd a siren modult:
-- siren = { enabled = true, alwaysVisible = false, order = 8 }
-- Egyéni pattern definiálása config.lua-ban
Config.Patterns['sajat_minta'] = {
    -- 1. lépés: extra 1+3 be, extra 2 ki, misc 0 be
    { extras = {[1]=true, [2]=false, [3]=true}, miscs = {[0]=true},  dur = 90  },
    -- 2. lépés: extra 2 be, extra 1+3 ki, misc 0 ki
    { extras = {[1]=false,[2]=true,  [3]=false}, miscs = {[0]=false}, dur = 90  },
    -- 3. lépés: szünet
    { extras = {[1]=false,[2]=false, [3]=false}, miscs = {[0]=false}, dur = 150 },
}

-- Pattern hozzárendelése egy stage-hez (pl. CODE 3):
Config.Stages[3].pattern = 'sajat_minta'

-- Vagy csak egy adott modellnél:
Config.VehicleConfigs['sheriff2'][3] = {
    pattern   = 'sajat_minta',
    sirenTone = 2,
}
