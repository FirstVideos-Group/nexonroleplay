Áttekintés

Az nxn-cityhall az önkormányzati rendszer, amely fizikai helyszínt és NPC-t biztosít az igazolvány kiváltáshoz, csekk befizetéshez és egyéb úgyekhez. Az NPC-t az nxn-npcconversation kezeli, az igazolványokat az nxn-licenses, bírságokat saját DB tábla tárolja.

Bővítés más resource-ból

Hozzáadhatsz új NPC beszélgetési opciót az addMenuItem kliensexportával. Ez egyszerre frissíti a konfigot és az nxn-npcconversation diálogus listáját is. 

-- nxn-police client.lua: saját ügy hozzáadása
AddEventHandler('onClientResourceStart', function(res)
    if res ~= 'nxn-cityhall' then return end

    exports['nxn-cityhall']:addMenuItem({
        id        = 'evidence',
        label     = 'Bizonyíték beadása',
        icon      = 'hgi-folder-security',
        response  = 'Rendeljék elő a beadási űrlapot.',
        action    = 'custom',
        eventName = 'nxn-police:client:openEvidenceForm',
    })
end)
Az action = 'custom' + eventName kombilációval bármely jovőbeli script (bíróság, rendorség, igazságszolgáltatás) dinamikusan adhat új működést az ügyintézőnek – az nxn-cityhall códja módosítása nélkül.

Példák

Bírság kiadás (Rendor)
Bírság visszavonás
Fizetetlen ellenőrzés
Jövőbeli script int.
-- nxn-police szerver: bírság kiadása (targetSrc = járő játékos)
local fineId = exports['nxn-cityhall']:issueFine(
    targetSrc,
    'Megillető helyen parkolás',
    5000,
    'Rendorség'
)
if fineId then
    print('Bírság ID:', fineId)
end
-- Bírság visszavonása (pl. bírósági felmentés)
local ok = exports['nxn-cityhall']:revokeFine(fineId)
print('Visszavonva:', ok)
-- Van-e ki nem fizetett bírság?
if exports['nxn-cityhall']:hasUnpaidFines(src) then
    local total = exports['nxn-cityhall']:getTotalFines(src)
    exports['nxn-notify']:notifyPlayer(src,
        ('Figyelem! $%d ki nem fizetett bírságod van.'):format(total),
        'warning'
    )
end
-- nxn-court (bíróság) ügy hozzáadása az Ügyintézőhöz:
exports['nxn-cityhall']:addMenuItem({
    id        = 'court_schedule',
    label     = 'Bírósági időpont',
    icon      = 'hgi-justice-scale-01',
    response  = 'A következő sz. időpont előfoglalva.',
    action    = 'custom',
    eventName = 'nxn-court:client:openSchedule',
})
