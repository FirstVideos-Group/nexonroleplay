nxn-food v1.0.0

Az nxn-food kezeli az étel/ital fogyasztást, az NPC éttermek és boltok vásárlási rendszerét, valamint az nxn-needs éhség/szomjúság/stressz/fáradtság módosítást. A vásárlás nxn-finance exportokon keresztül von le pénzt, az itemek az nxn-inventory-ba kerülnek.

Fájlstruktúra

nxn-food/
├── fxmanifest.lua      ← dependency: nxn-needs, nxn-inventory, nxn-notify, nxn-npcconversation, nxn-finance
├── config.lua          ← items, shops, árak, animációk
├── shared.lua          ← NXN.Food logger
├── client.lua          ← animáció, NPC regisztrálás, bolt UI, exportok
├── server.lua          ← fogyasztás logika, shop vásárlás, exportok
├── html/
│   ├── index.html
│   ├── style.css
│   └── app.js
└── docs/index.html

Export használati példák

e1 – Fogyasztás külső scriptből
e2 – isEating() ellenőrzés
e3 – Inventory integrálás
e4 – nxn-needs kapcsolat
-- Orvosi vagy más resource fogyasztást indít:
-- server.lua
local ok = exports['nxn-food']:consumeItem(src, 'water_bottle')
if not ok then
    print('Ismeretlen item vagy nxn-food nem fut.')
end
-- Kliens oldali ellenőrzés (pl. animáció blokkoláshoz):
-- client.lua
if exports['nxn-food']:isEating() then
    -- Játékos most eszik, ne tegyük lehetővé az interakciót
    return
end

-- Megszakítás kényszer esetén:
exports['nxn-food']:cancelConsume()
-- Az nxn-inventory az item használatakor triggereli:
-- (nxn-inventory konfigban be kell állítani az item use eventjét)
-- server.lua (nxn-inventory use handler)
TriggerEvent('nxn-food:server:use', source, 'hamburger')

-- Vagy közvetlenül:
RegisterServerEvent('nxn-food:server:use', function(itemName)
    -- ezt az nxn-food kezeli automatikusan
end)
-- A fogyasztás után az nxn-food automatikusan hívja:
-- server.lua (nxn-food belső logika)
exports['nxn-needs']:modifyNeed(src, 'hunger',  35)  -- hamburger
exports['nxn-needs']:modifyNeed(src, 'thirst',  -5)
exports['nxn-needs']:modifyNeed(src, 'stress',  -5)

-- Teli has ellenőrzés (getNeed export):
local hunger = exports['nxn-needs']:getNeed(src, 'hunger')
if hunger >= 90 then
    -- 'Már nem vagy éhes!' értesítés küldve
end

Kapcsolódó scriptek

ScriptKapcsolat

nxn-inventoryremoveItem (fogyasztás után), addItem (vásárlásnál), hasItem (ellenőrzés)
nxn-notifyFogyasztási és vásárlási visszajelzések (success / warn / danger)
nxn-npcconversationregisterNPC/unregisterNPC – éttermi NPC-k automatikus regisztrálása resource start/stop-kor
nxn-financegetMoney (ellenőrzés), removeMoney (vásárlásnál), addMoney (visszatérítésnél)
nxn-hudnxn-food:client:consumed eventet figyelheti a HUD animáció frissítéshez
nxn-shopHa nxn-shop telepítve van, a bolt logika delegálható registerShop exporton keresztül
