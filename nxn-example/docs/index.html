nxn-example v1.0.0

Ez a resource a Nexon FiveM boilerplate-je. Minden új script ebből indul ki – tartalmaz kliens/szerver kommunikációt, NUI panelt, értesítési rendszert és exportokat.

Fájlstruktúra

nxn-example/
├── fxmanifest.lua
├── config.lua
├── shared/shared.lua
├── client/client.lua
├── server/server.lua
└── html/ (index.html, style.css, app.js)

Exportok

Export neveOldalLeírás
openUI()clientMegnyitja a UI panelt
closeUI()clientBezárja a UI panelt
isUIOpen()clientVisszaadja, hogy nyitva van-e a UI
sendNotify(msg)clientÉrtesítést küld a játékosnak
notifyPlayer(src, msg)serverÉrtesítést küld egy adott játékosnak
broadcastNotify(msg)serverÉrtesítést küld minden játékosnak
openUIForPlayer(src)serverMegnyitja a UI-t egy adott játékosnál

Export használati példák

Kliens (Lua)
Szerver (Lua)
Másik resource-ból
-- UI megnyitása
exports['nxn-example']:openUI()

-- UI bezárása
exports['nxn-example']:closeUI()

-- Ellenőrzés
if exports['nxn-example']:isUIOpen() then
    print('A panel nyitva van')
end
-- Értesítés küldése egy játékosnak (src = player source)
exports['nxn-example']:notifyPlayer(src, 'Üdvözöllek a szerveren!')

-- Broadcast minden játékosnak
exports['nxn-example']:broadcastNotify('Szerver újraindul 5 perc múlva!')

-- UI megnyitása egy játékosnál
exports['nxn-example']:openUIForPlayer(src)
-- Egy másik nxn-* resource-ból is hívható:
-- client oldalon:
exports['nxn-example']:openUI()

-- server oldalon:
exports['nxn-example']:notifyPlayer(source, 'Hello a másik resource-ból!')
