nxn-garage v1.0.0

⚠️ Architektúra: Az nxn-garage kizárólag az nxn-vehicles exportjain át kommunikál az adatbázissal. Nem ír és nem olvas közvetlenül járműadatokat.

Az nxn-garage felelős a járművek spawn/despawn UX-ért, garázs-panel NUI-jáért, NPC interakcióért és helyszínek kezeléséért.

Függőségek

Kötelező nxn-vehicles – adatréteg (getVehicles, setStored, isOwner, getEngineHP...)
Kötelező nxn-database – getIdentifier
Kötelező nxn-notify – visszajelzések
Opcionális nxn-engine – setEngineHP / getEngineHP
Opcionális nxn-keys – giveKey(src/plate)
Opcionális nxn-trunk – clearTrunk(plate)
Opcionális nxn-npcconversation – registerNPC / unregisterNPC
Opcionális nxn-signs – registerZone

Működési folyamat

Spawn
Despawn
NPC regisztráció
Játékos → NUI "Kivesz"
    → nxn-garage:server:spawn { plate, garageId }
Szerver:
  isOwner(src, plate)        ✅
  getVehicle(plate).stored   ✅
  getVehicle(plate).impounded ✅
  getGarage(garageId)         ✅
  setStored(plate, false)
  getEngineHP(plate) → hp
  giveKey(src, plate)         (nxn-keys, opcionális)
  TriggerEvent('nxn-vehicles:server:spawned', src, plate, model)
Kliens:
  CreateVehicle(model, spawnCoords)
  SetVehicleNumberPlateText(plate)
  setEngineHP(hp)             (nxn-engine, opcionális)
Játékos → NUI "Elrak"
    → nxn-garage:server:despawn { plate, hp }
Szerver:
  isOwner(src, plate)  ✅
  saveEngineHP(plate, hp)
  setStored(plate, true)
  clearTrunk(plate)    (nxn-trunk, ha ClearTrunkOnDespawn)
  TriggerEvent('nxn-vehicles:server:despawned', src, plate)
Kliens:
  DeleteVehicle(veh)
  Notify('Jármű elrakva', 'success')
