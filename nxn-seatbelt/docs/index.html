nxn-seatbelt v1.0.0

Az nxn-seatbelt kezeli a biztonsági öv be/ki csatolását, a hang emlékeztetőt, blokkolja a kiszállást bekötött övnél, és közzéteszi az öv állapotát más resource-ok számára (traffipax, HUD, stb.).

Integráció: Az öv állapota elérhető nxn-seatbelt:stateChanged event-en és a kliens/szerver exportokon keresztül. Az nxn-notify resource-t használja értesítésekhez (fallback NUI notify ha nem elérhető).

Példák

Traffipax
HUD integráció
Szerver ellenőrzés
Event figyelés
-- nxn-traffipax/client.lua:
-- Traffipax ellenőrzi az öv állapotát
local buckled = exports['nxn-seatbelt']:isBuckled()
if not buckled then
    -- Bírság kiszabása
    TriggerServerEvent('nxn-traffipax:server:fine', {
        reason = 'Nem volt bekötve a biztonsági öv',
        amount = 15000,
    })
end
-- nxn-hud/client.lua:
-- Az nxn-seatbelt automatikusan hívja ezt az exportot
-- Ha kézzel is kell szinkronizálni:
AddEventHandler('nxn-seatbelt:stateChanged', function(data)
    -- data.buckled, data.inVehicle
    SendNUIMessage({ action = 'setSeatbelt', buckled = data.buckled })
end)
-- Szerver oldali ellenőrzés:
AddEventHandler('playerJoined', function()
    local src = source
    -- Kicsit később ellenőrzünk
    SetTimeout(5000, function()
        local buckled = exports['nxn-seatbelt']:isPlayerBuckled(src)
        print('Player ' .. src .. ' buckled: ' .. tostring(buckled))
    end)
end)
-- Event alapú figyelés más resource-ból:
AddEventHandler('nxn-seatbelt:stateChanged', function(data)
    if not data.buckled and data.inVehicle then
        -- Pl. rendőrségi riasztás, bírság, hangjelzés
        print('Játékos nincs bekötve!')
    end
end)

Hangfájl csere

Helyezd az egyedi .ogg hangfájlt a sounds/ mappába, majd a config.lua-ban add meg a nevet:

Config.ReminderSound = 'sounds/sajat_hang.ogg'
Megjegyzés: A hangfájlt az fxmanifest.lua files blokkjában is fel kell tüntetni, pl.: 'sounds/sajat_hang.ogg'

Debug

Config.Debug = true esetén minden öv-változás, hang-indítás/leállítás, export-hívás és HUD broadcast megjelenik [nxn-seatbelt] [DEBUG] prefixszel a konzolban.
