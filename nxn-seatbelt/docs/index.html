nxn-seatbelt v1.0.0

Az nxn-seatbelt kezeli a játszos biztonsagi övét: be- és kicsatolás, figyelmezteto hang, kiszalás blokkálás és export API más resource-ok (traffipax, rendorseg) számára. Automatikusan szinkronizál az nxn-vehicle-hud-dal.

Integrációk: nxn-vehicle-hud (setSeatbelt), nxn-notify (ertesitesek)

Allapot lekérdezés
-- nxn-traffipax/client.lua
local function CheckSeatbelt()
    if GetResourceState('nxn-seatbelt') ~= 'started' then return end

    local isFastened = exports['nxn-seatbelt']:isFastened()
    local isInCar    = exports['nxn-seatbelt']:isInVehicle()

    if isInCar and not isFastened then
        -- Birsagolasi logika
        TriggerServerEvent('nxn-traffipax:server:fine', {
            reason = 'Nincs bekapcsolva a biztonsagi ov',
            amount = 15000
        })
    end
end
-- Rendorsegi ellenorzes - ov allapot lekerdezes
local isFastened = exports['nxn-seatbelt']:isFastened()
if not isFastened then
    exports['nxn-notify']:send('Nincs bekotve a biztonsagi ov!', 'danger')
end

-- Kiszallas utan auto kicsatolas (pl. mentese)
exports['nxn-seatbelt']:setFastened(false)
-- Allapot lekerdezes + HUD szinkron manualis kenyszeritessel
local seatbeltOk = exports['nxn-seatbelt']:isFastened()
local inCar      = exports['nxn-seatbelt']:isInVehicle()

print(('Ov: %s | Jarmuben: %s'):format(
    tostring(seatbeltOk),
    tostring(inCar)
))

-- Figyelmeztetes manualis lejatszasa
exports['nxn-seatbelt']:playWarning()

nxn-vehicle-hud integráció

Az ov allapota automatikusan továbbítódik az nxn-vehicle-hud setSeatbelt(fastened) exportjához minden állapotváltozáskor. Ha az nxn-vehicle-hud nincs elindítva, a rendszer figyelmeztet de nem omlik össze.

-- Automatikusan meghivja (nxn-seatbelt belsejeben):
exports['nxn-vehicle-hud']:setSeatbelt(true)   -- bekotes
exports['nxn-vehicle-hud']:setSeatbelt(false)  -- kicsatolas

Debug

Config.Debug = true eseten minden allapotvaltozas, hang event es HUD szinkron megjelenik [nxn-seatbelt] [DEBUG] prefixszel a konzolban.
