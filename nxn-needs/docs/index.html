nxn-needs v1.0.0

Az nxn-needs kezeli a játékos alapvető szükségleteit: éhség, szomjúság, stressz, fáradtság. Az adatokat az nxn_needs táblában tárolja, az nxn-database registerTable exportján keresztül regisztrálva. A HUD resource az exportokat és a kliens eventet használhatja a megjelenítéshez.

Függőségek: oxmysql, nxn-database – mindkettőnek futnia kell az nxn-needs előtt.

Export használati példák

Evés / ivás
Stressz kezelés
HUD figyelés (kliens)
Admin reset
getNeed ellenőrzés
-- nxn-food resource server.lua-jában:
-- Hamburger evése: hunger +35
exports['nxn-needs']:modifyNeed(source, 'hunger', 35)

-- Víz ivása: thirst +40
exports['nxn-needs']:modifyNeed(source, 'thirst', 40)

-- Pontos beállítás
exports['nxn-needs']:setNeed(source, 'hunger', 100)
-- Stressz növelése (pl. lövöldözés után):
exports['nxn-needs']:modifyNeed(source, 'stress', 20)

-- Stressz csökkentése (pl. masszázs után):
exports['nxn-needs']:modifyNeed(source, 'stress', -30)

-- Fáradtság lekérdezése döntéshozatalhoz:
local fatigue = exports['nxn-needs']:getNeed(source, 'fatigue')
if fatigue > 80 then
    -- játékos lassabb legyen
end
-- nxn-hud client.lua-jában:
-- Figyeli az nxn-needs frissítési eventjét:
AddEventHandler('nxn-needs:client:updated', function(needs)
    -- needs = { hunger, thirst, stress, fatigue }
    SendNUIMessage({
        action = 'updateNeeds',
        needs  = needs
    })
end)

-- Vagy direkt lekérdezés:
local needs = exports['nxn-needs']:getLocalNeeds()
local hunger = exports['nxn-needs']:getLocalNeed('hunger')
-- Admin parancsban:
RegisterCommand('resetneeds', function(src, args)
    local target = tonumber(args[1]) or src
    exports['nxn-needs']:resetNeeds(target)
end, true)

-- Ellenőrzés előtte:
local needs = exports['nxn-needs']:getNeeds(target)
if needs then
    print('Hunger: ' .. needs.hunger .. ' | Thirst: ' .. needs.thirst)
end
-- Szerver oldalon – éhes-e a játékos?
local hunger = exports['nxn-needs']:getNeed(source, 'hunger')
if hunger ~= nil and hunger < 20 then
    -- Figyelmeztető üzenet küldése
    exports['nxn-database']:setMeta(source, 'isHungry', true)
end

Net Events

Event neveIrányLeírás
nxn-needs:server:requestSyncClient → ServerKliens szinkronizációt kér (spawn után)
nxn-needs:client:syncServer → ClientSzerver elküldi a friss needs adatokat
nxn-needs:client:applyDamageServer → ClientHP csökkentés (hunger/thirst = 0)
nxn-needs:client:updatedClient (local event)Lokális event – HUD figyelheti a frissülést
nxn-needs:server:needsLoadedServer (local event)Needs betöltve – más resource-ok figyelhetik
HUD integráció: Az nxn-hud resource a nxn-needs:client:updated lokális eventet hallgatja, és az exports['nxn-needs']:getLocalNeeds() exportot hívja az adatok megjelenítéséhez. Szerver oldalon a getNeeds(src) / getNeed(src, need) exportok elérhetők bármely más resource-ból.

Debug logok

A Config.Debug = true beállítással részletes naplókat kapsz minden DB-műveletről, cache-hozzáférésről, AutoDecay tickről és szinkronizációról. Éles szerveren kapcsold ki.
