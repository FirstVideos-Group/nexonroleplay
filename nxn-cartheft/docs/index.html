nxn-cartheft v1.0.0

Az nxn-cartheft a Nexon RP szerver autófeltörési rendszere. Két interaktív minijátékot tartalmaz (lockpick és keypad/Simon Says), és szorosan integrálódik az nxn-engine, nxn-keys és nxn-vehicles scriptekkel.

Export használati példák

Szerver (Lua)
Kliens (Lua)
nxn-police integráció
-- Folyamatban van-e feltörés egy adott járművön?
if exports['nxn-cartheft']:isBeingBrokenInto('ABC-123') then
    print('Feltörés folyamatban!')
end

-- Kísérletek száma
local count = exports['nxn-cartheft']:getAttemptCount('ABC-123', identifier)

-- Visszazárás (rendőr parancsra)
exports['nxn-cartheft']:lockVehicleAgain('ABC-123')
-- Feltörés indítása egy adott járművön
local veh = GetClosestVehicle(...)  -- saját logika
exports['nxn-cartheft']:startBreakIn(veh)

-- Van-e aktív feltörés?
if exports['nxn-cartheft']:isBreakingIn() then
    print('Éppen feltör valamit')
end

-- Megszakítás
exports['nxn-cartheft']:cancelBreakIn()
-- nxn-police/server.lua
AddEventHandler('nxn-cartheft:server:attemptLogged', function(src, plate, success, coords)
    if success then
        TriggerClientEvent('nxn-police:client:alert', -1, {
            type    = 'cartheft',
            message = 'Járműfeltörés – rendszám: ' .. plate,
            coords  = coords,
        })
    end
end)

Biztonsági ellenőrzések

1
Cooldown – AttemptCooldown másodperc várakozás próbálkozások között
2
nxn-keys:hasKey – ha van kulcsa, nem indulhat el a feltörés
3
nxn-vehicles:isOwner – saját járművet nem tör fel
4
isBeingBrokenInto – konkurens feltörés megakadályozása
5
MaxAttemptsPerVehicle – kísérletszám limit járművenként
6
Közelség re-ellenőrzés – szerver oldali coords ellenőrzés
