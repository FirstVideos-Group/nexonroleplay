nxn-fuel v1.0.0

Az nxn-fuel a Nexon RP üzemanyag-kezelő rendszere. Fogyasztásszimulációt, DB-perzisztenciát és HUD-integrációt biztosít. Nincs NUI – csak adatot kezel és pushol a HUD scriptek felé. A töltőállomásokat és a fizikai tankálást a jövőbeli nxn-gasstation script kezeli.

nxn-vehicle-hud integráció
-- nxn-gasstation/server.lua (jövőbeli script)
RegisterNetEvent('nxn-gasstation:server:refuel', function(plate, amount)
    local src = source
    local newLevel = exports['nxn-fuel']:addFuel(plate, amount)
    TriggerClientEvent('nxn-fuel:client:sync', src, { plate=plate, level=newLevel })
end)

-- Tank méret lekérdezés
local tankSize = exports['nxn-fuel']:getTankSize('ABC-123')

-- Szint lekérdezés/beállítás
local level = exports['nxn-fuel']:getFuel('ABC-123')
exports['nxn-fuel']:setFuel('ABC-123', 75.0)
-- Aktuális szint (nil ha nem vezet)
local level = exports['nxn-fuel']:getCurrentFuel()

-- Alacsony-e?
if exports['nxn-fuel']:isFuelLow() then
    print('Alacsony üzemanyag!')
end

-- Üres tank figyelés
AddEventHandler('nxn-fuel:empty', function(plate)
    print('Tank üres: ' .. tostring(plate))
end)

Fogyasztási képlet

-- Mozgás közben:
consumption = (Config.BaseConsumption + speed_kmh * Config.SpeedMultiplier) * elapsed_sec

-- Alapjáraton (speed < 2 km/h):
consumption = Config.IdleConsumption * elapsed_sec

-- Pl. 80 km/h-n, 2 másodpercenként:
-- (0.003 + 80 * 0.0001) * 2 = (0.003 + 0.008) * 2 = 0.022 liter / tick

Adatfolyam

1
Járműbe szállás – requestFuel szerver event, HUD modul megjelenítés
2
Szerver válasz – DB SELECT + client:sync visszaküldés
3
Fogyasztási loop – PollInterval ms-onként, sebességarányos számítás
4
HUD push – ≥0.1L változásnál setFuel() + updateModuleData() hívás
5
Low fuel – <15% esetén nxn-notify warning (60mp cooldown)
6
Empty – nxn-engine:forceOff vagy natív SetVehicleEngineOn(false)
7
DB mentés – 30mp-onként throttle-zva + kiszálláskor azonnali mentés
