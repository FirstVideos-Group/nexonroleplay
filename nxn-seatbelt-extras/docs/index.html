nxn-seatbelt-extras v1.0.0

Az nxn-seatbelt-extras kiegészíti az nxn-seatbelt rendszert fizikai öv-hatásokkal: kireputélés, sérülés, effektek. Minden viselkedés konfigurálható threshold-okkal és szorzókkal.

Függőség: Az nxn-seatbelt resource futnia kell. A script a dependencies listaból automatikusan elindatja.

Példák

Balesetet-észlelő
Traffipax integráció
Ejection tiltasa (példa)
-- Automatikus baleset-észlelő integráció:
AddEventHandler('nxn-seatbelt-extras:collision', function(data)
    if data.type == 'major' and not data.fastened then
        -- Mentső kiváltása
        TriggerServerEvent('nxn-emergency:server:accident', {
            deltaV   = data.deltaV,
            fastened = data.fastened,
            coords   = GetEntityCoords(PlayerPedId()),
        })
    end
end)

-- Kireputélés esemény:
AddEventHandler('nxn-seatbelt-extras:ejected', function(data)
    print('Kireputélés! deltaV: ' .. data.deltaV)
end)
-- Traffipax: kicsatolt öv ellenorzése + ütközés
AddEventHandler('nxn-seatbelt-extras:collision', function(data)
    local isFastened = exports['nxn-seatbelt']:isFastened()
    if not isFastened and data.deltaV > 40 then
        TriggerServerEvent('nxn-traffipax:server:fine', {
            reason = 'Biztonsagi ov kicsatolva + baleset',
            amount = 25000
        })
    end
end)
-- Ejection tiltasa (pl. rendorsegi mentes)
exports['nxn-seatbelt-extras']:setEjectionEnabled(false)

-- Manualis szimulacio (pl. IED baleset)
exports['nxn-seatbelt-extras']:simulateCrash(85.0)  -- 85 km/h deltaV

-- Threshold dinamikus allitasa
exports['nxn-seatbelt-extras']:setEjectionThreshold(45.0)  -- alacsonyabb kuszob

Debug

Config.Debug = true eseten minden sebesseg-mintavetel, utkozest-esléelés es effekt-alkalmazas megjelenik [nxn-seatbelt-extras] [DEBUG] prefixszel. Tipp: először csak Major collision sorokra szűrj rá.
