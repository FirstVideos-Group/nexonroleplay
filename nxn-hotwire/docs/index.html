nxn-hotwire v1.0.0

Az nxn-hotwire a Nexon RP szerver kulcs nélküli motorindítási rendszere. Az nxn-engine:hotwireStart() exporton keresztül kerüli meg az nxn-keys auth callbacket. Két interaktív minijátékkát tartalmaz (wirechoice és sequence/QTE).

2 lépéses autólopás folyamat

→
🚗 Játékos belül
→
⚡ nxn-hotwire

→

Kódpéldák

Szerver (Lua)
Kliens (Lua)
nxn-police integráció
-- Folyamatban van-e hotwire?
if exports['nxn-hotwire']:isBeingHotwired('ABC-123') then
    print('Hotwire folyamatban!')
end

-- Kísérletek száma
local count = exports['nxn-hotwire']:getAttemptCount('ABC-123', identifier)
-- Hotwire indítása
local veh = GetVehiclePedIsIn(PlayerPedId(), false)
exports['nxn-hotwire']:startHotwire(veh)

-- Megszakítás
exports['nxn-hotwire']:cancelHotwire()
-- nxn-police/server.lua
AddEventHandler('nxn-hotwire:server:attemptLogged', function(src, plate, success, coords)
    if success then
        TriggerClientEvent('nxn-police:client:alert', -1, {
            type     = 'hotwire',
            message  = 'Jármű beindítás kulcs nélkül – rendszám: ' .. plate,
            coords   = coords,
            priority = 'high',
        })
    end
end)
