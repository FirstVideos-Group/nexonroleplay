Áttekintés

Az nxn-inventory a Nexon RP szerver alap inventory és itemkezelő rendszere. Játékosonként tárolja az itemeket adatbázisban, súlyrendszerrel működik, tartalmaz hotbart, jobb klikkes kontextmenüt, és teljes export API-t nyújt más resourceoknak (pl. nxn-trunk, shopok, szállítási scriptek).

→ NUI / Lua

→ export
nxn-database
↔ modifyNeed

Példa – új item hozzáadása

Config.Items['coffee'] = {
    label     = 'Kvé',
    icon      = 'hgi-coffee-01',
    weight    = 0.3,
    stackable = true,
    maxStack  = 5,
    usable    = true,
    useAction = 'nxn-inventory:use:coffee',
    needs     = { fatigue = -10, thirst = 15 },
    category  = 'food',
}

Használati példák

Item hozzáadása más resource-ból (szerver)

addItem
removeItem / hasItem
Item használat figyelese
nxn-trunk int.
-- Szerver oldal: item hozzáadása
local ok, err = exports['nxn-inventory']:addItem(src, 'water_bottle', 2)
if ok then
    exports['nxn-notify']:notifyPlayer(src, 'Kaptad: 2x Vízespohár', 'success')
else
    exports['nxn-notify']:notifyPlayer(src, err, 'warning')
end
-- Van-e nála legalább 1 szendvics?
if exports['nxn-inventory']:hasItem(src, 'sandwich', 1) then
    exports['nxn-inventory']:removeItem(src, 'sandwich', 1)
    -- ... feldolgozás
end
-- nxn-trunk vagy más script figyeli a használat eseményt
AddEventHandler('nxn-inventory:server:itemUsed', function(src, itemName, def)
    if itemName == 'keys' then
        -- Jel kulcs használatnál
        TriggerClientEvent('nxn-vehicle:client:toggleLock', src)
    end
end)

-- Vagy a config-ban definiált useAction event figyelhető:
AddEventHandler('nxn-inventory:use:water_bottle', function(src)
    print(('src=%d ivott egy pohár vizet'):format(src))
end)
-- nxn-trunk szerver oldal (jövőbeli script)
-- Csomagtartóból itemek átmozgatása az inventory-ba:
local ok, err = exports['nxn-inventory']:addItem(src, itemName, count)
if not ok then
    exports['nxn-notify']:notifyPlayer(src, err, 'warning')
    return
end
-- Trunk-ból kiveszükés notify
exports['nxn-trunk']:removeFromTrunk(vehicle, itemName, count)
exports['nxn-notify']:notifyPlayer(src, 'Tvitte: ' .. itemName, 'success')

Kliens oldal

-- Inventory programmatikus megnyitása kliens script-ből:
exports['nxn-inventory']:openInventory()

-- Helyi súly lekérése:
local w = exports['nxn-inventory']:getLocalWeight()
print(('Jelenlegi súly: %.2f kg'):format(w))
Az nxn-trunk resource az addItem / removeItem exportokon keresztül kezeli már most is az inventory rendszert – a trunk script elkészítése után nem szükséges módosítás ezen a scripten.
A nxn-inventory-t az ensure listában az nxn-database és nxn-needs után kell elindítani.
