nxn-gasstation v1.0.0

Az nxn-gasstation a Nexon RP szerver töltőállomás rendszere. Kezeli a tankálási interakciót (marker + NPC alapú), a fizetést az nxn-finance-en keresztül, és az üzemanyag hozzáadását az nxn-fuel exportján át.

exports['nxn-gasstation']:startRefuel(vehicle, 'paleto_bp')

-- Tankálás alatt van?

    print('Tankálás folyamatban')

-- Megszakítás

Működési folyamat

1. Játékos megközelíti a pumpát (marker / NPC)
2. [E] vagy NPC dialóg → UI megnyílik (aktuális szint, max. liter, ár)
3. Játékos beállítja a litert → megerősíti
4. startRefuel → szerver ellenőrzi közelséget, tankálási zárat, pénzegyenleget
5. refuelAllowed → kliens animációt indít, várakozik (liter / sebesség másodperc)
6. confirmRefuel → szerver: nxn-finance:removeMoney + nxn-fuel:addFuel + DB log
7. refuelDone → animáció leáll, értesítés jelenik meg
